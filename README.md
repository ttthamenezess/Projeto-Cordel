# 📜 Projeto Cordel

Projeto web inspirado no cordel **"Cordel Moderno"**, de **Milton Duarte**, desenvolvido com **HTML5** e **CSS3**.

O objetivo do projeto é praticar estruturação de páginas, estilização com CSS e efeitos visuais utilizando imagens de fundo e efeito parallax.

## 📌 Visão Geral

O **Projeto Cordel** é uma página web que apresenta um poema em formato visual, com seções estilizadas e imagens de fundo.

A proposta do projeto é unir literatura e tecnologia, criando uma experiência de leitura mais imersiva por meio de HTML e CSS.

---

## ⚙️ Funcionalidades

- 📖 Exibição de poema em formato de página web
- 🎨 Estilização com CSS
- 🖼️ Uso de imagens de fundo
- 🌌 Efeito visual com parallax
- 📱 Layout adaptável para diferentes telas
- 🌐 Publicação via GitHub Pages
